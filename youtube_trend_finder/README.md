# ゲームShortsトレンドファインダー

「クロのゲーム情報局」向けに、今伸びているゲーム系YouTube Shortsを集めて、今日作る企画を10本出すツールです。

やっていることは次の流れです。

1. 過去7日（と直近24時間）の日本語ゲームShortsを集める
2. 再生の速さ、登録者数との比、コメント率で点数を付ける
3. 似たタイトルをまとめて、「複数チャンネルで同時に伸びているテーマ」を探す
4. 自分の過去動画・競合の過去動画と照らす
5. `reports/` に、今日作るべき企画TOP10を書く

再生数が多いだけの動画や、登録者が多いだけの動画が上位を独占しにくいようにしてあります。

## フォルダ

```
youtube_trend_finder/
  main.py                 実行口
  config.py               点数の重み、期間、予算
  .env                    APIキー（自分で作る。Gitには上げない）
  .env.example            記入例
  requirements.txt
  config/search_keywords.txt
  config/exclude_keywords.txt
  src/                    取得・分析・レポート
  data/existing/          過去CSVを置いてもよい
  data/daily/             日次のCSV
  data/cache/             APIのキャッシュ
  reports/                毎日のMarkdown
```

手元に次のCSVがある場合は、自動で探します。移動も削除もしません。

- `kuro_youtube_40.csv` … 自チャンネルの過去動画
- `other_channels_youtube_75.csv` … 競合の過去動画

探場所は、このフォルダ、一つ上のフォルダ、`data/existing/` です。列名が違っても、タイトルや再生回数として読めるものは読み替えます。

## 1. Google Cloudで YouTube Data API v3 を有効にする

1. ブラウザで [Google Cloud Console](https://console.cloud.google.com/) を開く
2. Googleアカウントでログインする
3. 画面上部のプロジェクト選択から「新しいプロジェクト」を作る（名前は `youtube-shorts-trend` などでよい）
4. 左メニューの「APIとサービス」→「ライブラリ」
5. 検索欄に `YouTube Data API v3` と入れる
6. 「YouTube Data API v3」を開き、「有効にする」を押す

有効にしないと、キーがあっても動画は取れません。

## 2. APIキーを取得する

1. 左メニューの「APIとサービス」→「認証情報」
2. 「認証情報を作成」→「APIキー」
3. 作られたキーをコピーする
4. キーの編集画面で、アプリケーションの制限はいったん「なし」でも動きます
5. APIの制限で「キーを制限」を選び、`YouTube Data API v3` だけにチェックする（おすすめ）

キーはパスワードと同じです。チャットやGitHubに貼らないでください。

YouTube Data APIには1日の無料枠があります（通常10,000ユニット）。このツールは検索1回を100ユニットとして数え、1回の実行が予算（初期値6,500）を超えないように止めます。

## 3. .env への記入

このフォルダで、`.env.example` をコピーして `.env` を作ります。

```bash
cd youtube_trend_finder
cp .env.example .env
```

`.env` を開き、次のようにキーだけを書きます。`xxxxxxxx` は自分のキーです。

```
YOUTUBE_API_KEY=xxxxxxxx
```

引用符は不要です。行の前後に空白を入れない方が安全です。

## 4. 必要なライブラリ

Python 3.10以上を想定しています。

```bash
cd youtube_trend_finder
pip install -r requirements.txt
```

## 5. 実行

```bash
cd youtube_trend_finder
python main.py
```

これだけで、取得、CSV、分析、ランキング、企画TOP10、Markdownまで進みます。

APIキーを入れる前に、画面の形だけ見たいときは次です。数字はサンプルで、実在の再生数ではありません。

```bash
python main.py --demo
```

前回のキャッシュだけで集計し直すときは次です。APIは呼びません。

```bash
python main.py --skip-api
```

## 6. 結果を見る場所

| ファイル | 内容 |
| --- | --- |
| `reports/daily_report_YYYY-MM-DD.md` | 今日のテーマTOP10と、作るべき企画TOP10 |
| `data/daily/trend_raw_YYYY-MM-DD.csv` | 取得した動画の全部 |
| `data/daily/trend_ranked_YYYY-MM-DD.csv` | 企画向きに並べた一覧 |

日付は日本時間です。デモのときは `reports/demo_report_YYYY-MM-DD.md` になります。

企画は次の型に寄せています。

- 0.0〜1.0秒: ゲーム映像と強い一言
- 1.0〜1.5秒: 短いタイトル
- 1.5秒〜: すぐランキング（順位、作品名、反応2つ）
- 最後: 短い締めとコメント誘導
- 想定の長さ: 45〜50秒

タイトル案は参考動画のコピーではありません。20〜35文字を目安に、別の言い方へ変えています。

## 7. 検索キーワードを変える

`config/search_keywords.txt` を編集します。1行に1語です。`#` で始まる行はメモです。

上にある語から検索します。APIの予算が尽きたときは、下の語から削られます。具体的な語（PS2、鬱ゲーなど）を上に、広い語（ゲーム）を下に置くと無駄が減ります。

点数の割合を変えるときは `config.py` の `TREND_WEIGHTS` と `OPPORTUNITY_WEIGHTS` です。合計が1でなくても、実行時に比率へ直します。

初期値は次です。

- Trend Score: 再生速度 35%、登録者比 30%、コメント率 15%、いいね率 10%、新しさ 10%
- Opportunity Score: Trend 45%、自チャンネルとの相性 25%、競合の過去実績 15%、複数チャンネルでの同時発生 15%

外したい語は `config/exclude_keywords.txt` です。Minecraft、切り抜き、事前登録などはここに入っています。

## 8. APIクォータを超えたとき

YouTubeの無料枠は、太平洋時間の日付が変わると戻ります。日本時間では、夏時間のあいだはおよそ16時、冬時間のあいだはおよそ17時です。

超えたときの動きは次です。

- 画面に日本語で「上限に達した」と出る
- プログラム全体は落ちない
- 取れた分と、`data/cache/` の前回データでレポートを作る
- 同じ日にもう一度実行すると、検索結果のキャッシュがあれば search.list（100ユニット）をやり直さない

枠を節約している点は次です。

- キーワードごとに、過去7日と過去24時間だけ検索する（過去3日は、取った動画の公開時刻で分ける）
- 動画の詳細は50件ずつ `videos.list`（1ユニット）でまとめて取る
- チャンネルも50件ずつ `channels.list`（1ユニット）でまとめて取る
- 同じ動画・同じチャンネルはキャッシュ期間（初期12時間）のあいだ再取得しない

キャッシュを捨てて取り直すときは、`data/cache/` の中だけ削除してください。`.env` や過去CSVは消さないでください。

予算の上限は `config.py` の `DAILY_QUOTA_BUDGET` です。公式の1日10,000より小さくしてあります。

## よくあるメッセージ

| メッセージ | 意味と対処 |
| --- | --- |
| APIキーが未設定 | `.env` に `YOUTUBE_API_KEY` が無い。キーを書いて再実行 |
| APIキーが無効 | キーの打ち間違い、または YouTube Data API v3 が無効 |
| 利用上限に達しました | その日は待つ。キャッシュがあれば `--skip-api` で集計だけできる |
| 通信に失敗しました | ネットを確認して再実行。キャッシュがあればそれを使う |
| CSVが見つかりません | 分析は続く。相性スコアは50点の中立になる。CSVを置くと精度が上がる |
| 条件に合う動画がない | キーワードを増やす。レポートにはその旨が出る |
| 登録者数が空欄 | チャンネルが登録者数を非公開にしている。エラーではない |

登録者数が非公開の動画は、登録者比を「分かっている動画の中央値」にしたうえで少し下げます。空欄のままCSVに出します。

## 点数の意味

- **再生速度**: 再生数 ÷ 公開からの時間。公開3時間未満は、分母を3時間にして数字が暴れるのを抑えます。
- **登録者比**: 再生数 ÷ 登録者数。1万人のチャンネルで10万再生なら10倍です。企画そのものが強いサインとして重く見ます。
- **コメント率**: コメント数 ÷ 再生数。自分の体験を書きたくなるテーマを優先します。再生数が少なすぎる動画は、率を信用しません。
- **Channel Fit**: 自チャンネルの過去動画のなかで、相対的に再生が良かったテーマとの近さです。
- **複数チャンネル**: 1本だけ伸びているテーマより、別チャンネルで似たタイトルが同時に伸びているテーマを高くします。同じチャンネルの動画が並びすぎるときは下げる。

Minecraft、Roblox、Fortnite、VTuber切り抜き、スマホゲームの事前登録は、ランキングと企画から外します。実況や速報は、企画として使える可能性があるので除外はせず、点数だけ下げます。
